# 人相講座 上級編・第4回 ノート

出典: `docs/kouza-transcripts/advanced/kouza-adv4.srt`。通しテーマは
`KOUZA_ADV_OVERVIEW.md`参照。

## この回の内容(今回いちばんの収穫)

- 教科書「訴訟第1条」以降を詳しく解説。**このアプリの既存実装(天中を
  経路に含む線=先祖の加護/裁判の相)の裏付けとして、これまでで最も
  具体的な内容**だった:

  > 「天中場所にどっからでもいいですけど線が入ると振動線です...天中
  > 必ず登る。これ裁判。ここへ登るのが裁判です。これ登るか登らんかで
  > 裁判になるかならんかが決まります。」

  → 色以前に、**天中まで線が達しているかどうか自体が重要な判定基準**
  という説明。これを受けて`app/app.js`の該当箇所(色がはっきりしない
  場合の説明文)に一文追加した(`KOUZA_ADV_OVERVIEW.md`テーマ3参照)。

- **論難級**(天中の左右、日角・月角のあたり): 訴訟の相手方が画想として
  現れる場所。1人・2人・3人と複数の画想が出れば、それだけ相手方が
  複数いることを示すとされる。座標は既存の「父母」領域と近い可能性が
  あるが確証はなく、未実装。
- **警察級**: 天中付近にあるとされる、刑事事件がらみかどうかを見る場所。
  座標不明のため未実装。

## コードへの反映

- `app/app.js`の天中ライン解釈(色不明時のフォールバック文言)に、
  「天中に達していること自体が重要」という一文を追加。

## 次回への申し送り

論難級・警察級の座標が特定できれば(実物の図があれば)、`face-region-map.js`
への追加を検討したい。
