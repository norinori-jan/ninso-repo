# 人相講座3(全6回中3回目)動画からのノート

出典: 講座3の自動字幕(YouTube限定公開・日本語)。講座1・2と同様、個別
受講者(実名)への具体的な鑑定内容は除外し、一般化できる技法のみを
抜き出している。

**今回の方針(講座2の内容を踏まえての訂正後):** 部位の意味合い・定義は
安易に書き換えず、**鑑定の技法(検出したものをどう読むか)にあたる内容
だけ**を実装の候補として検討する。定義そのものに関わる話は、ノートに
記録するだけに留め、コードは変更していない。

## 鑑定の手順(参考情報・未実装)

講座3では、鑑定の進め方として次のような順序が説明されていた:

1. まず生年月日(何年何月生まれで今何歳か)を聞く
2. 父母の状態(仲が良いか、健在か)を髪際・天中付近の色から確認する
3. 兄弟の有無を髪際の模様(ご先祖からの「印」とされる)から確認する
4. 結婚しているか、何歳で結婚したかを流年法と照らして確認する

これは自動画像解析1回で完結する今のアプリの設計(選んだマーク単体を
独立して解釈する)とは前提が異なる、**対話形式の鑑定手順**。今のアプリ
に直接組み込むものではないため、参考情報として記録するに留める。

## 色についての追加情報(参考情報・未実装)

- 金運に関する部位(准頭・小鼻・福堂まわり)で、赤みがかった色は
  「炎のような色」と表現され、良くない徴候とされていた。
- 小鼻(金甲)から出る線は金銭の貸し借りを表すとされ、線の元が太く
  先が細い場合は「お金が入ってくる」、逆に色が悪ければ「貸したお金が
  返ってこない」といった読み方が説明されていた。ただし、線の「元と先の
  太さの違い」や「向き」を静止画から自動判定するのは、今の検出器
  (`pattern-detector.js`)の設計では難しく、実装は見送った。
- 天中まわりの悪い色(暗い・薄暗い)は、警察・裁判沙汰に関わるという
  説明が改めてあった。これは前回(講座2)ですでに実装済みの内容と一致
  している。

## 意図的に実装しなかった内容

- 「顔色が白っぽいと、その人(親など)が亡くなっている」という趣旨の
  発言があった。これは人の生死に関する断定的な予言にあたり、**このアプリ
  の方針として実装しない**。娯楽としての人相解釈と、生死に関わるような
  重い断定は切り分けるべきだと判断した。
