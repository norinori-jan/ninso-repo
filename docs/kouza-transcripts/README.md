# 講座字幕(基本編、全6回)

「人相講座」(基本編、全6回)動画のYouTube自動字幕(srt形式・日本語)を
そのまま保存したもの。動画本体(数百MB〜)はリポジトリに含めず、テキスト
の字幕だけを置いている。

## 置いている理由

- 動画ファイルはgitリポジトリで扱うには大きすぎる(1本あたり200MB〜
  500MB超)。字幕テキストなら1本あたり150〜200KB程度で、リポジトリに
  含めても問題にならない。
- タイムスタンプ(`00:00:03,439 --> 00:00:06,359`のような形式)を残して
  あるので、後から「この解釈はどの発言に基づいているか」を動画の該当
  箇所に遡って確認できる(動画とのリンク)。
- 講座の内容を後から読み返して、`face-region-map.js`や
  `hidden-face-engine.js`の記述との整合性を確認したり、新しい回の内容と
  見比べたりする際の一次資料として使う。

## 注意

- YouTubeの自動音声認識によるものなので、専門用語・数字・固有名詞に
  誤りが多く含まれる。特に数値(部位の座標・年齢など)は、この字幕
  だけを根拠に実装しない方がよい。
- 講座内でその場の受講者(実名)に対して行われた個別の鑑定内容は、
  各`KOUZAn_NOTES.md`側で意図的に除外している(個人情報のため)。
  この字幕ファイル自体には実名を含む発言がそのまま残っているので、
  再配布・公開の際は注意すること。
