# 人相講座6(基本編・最終回、実演あり)動画からのノート

出典: 講座6の自動字幕(YouTube・日本語、実演あり)。これまでと同様、
個別受講者(実名)への具体的な鑑定内容は除外し、一般化できる技法のみを
抜き出している。ユーザーからは「この回のモデルの方は顔相がはっきり
出ていて参考になる」との共有があった。

**今回もコード変更は基本方針を継続。** 新出内容の多くは、これまでに
確立した「実装しない」基準(健康・生死の断定、対話前提の技法、座標不明)
のいずれかに該当した。

## 新しく出てきた内容(参考記録・実装は見送り)

- **白目の色(青みがかっている)= 貧血・子供っぽさの表れ**、**白いホクロ
  =皮膚病の可能性**、といった、健康状態を顔・体の特徴から読む話が
  複数回出てきた。これまでの方針(健康・生死の断定はしない)により実装
  していない。
- **手相(指の長さ・爪・傷)についての言及**があった(親指=父、他の指=
  母、指の怪我が親族の命日や体調と関係する、など)。これは**顔相
  (face)ではなく手相(palm)という別モダリティ**であり、写真の撮り方
  ・検出対象がまったく異なる。今のアプリ(顔画像1枚を解析する設計)を
  拡張する話としては規模が大きすぎるため、今回は着手せず、将来的に
  「手相版」を作るかどうかの検討事項として記録するに留める。
- **画想が文字や数字の形に見える場合がある**という話があった。これは
  既存の「目・口が見える」パターンとは別の、より自由度の高いパレイ
  ドリアで、自動検出は現実的ではないため実装しない。

## 「画想」「振動線」の裏付けが今回も多数

配偶者の顔がそのまま画想として浮かび、実際の外見と一致していた、という
実演があった。これも講座2・4・5に続く、既存の点3つ表示機能の妥当性の
裏付け。振動線(白っぽい線、幅1mm程度、角度を変えると見え隠れする)に
ついても改めて具体例が示された。

## 「画想辞典」の存在(将来の参考資料)

講座6の最後で、部位ごとの画想の意味をまとめた資料(「画想辞典」)が
これから配布される、という案内があった。**この資料自体はまだ入手して
いない。** もし今後入手できれば、`face-region-map.js`の`meaning`拡充や、
`docs/`配下への新規リファレンスとして反映できる可能性がある。次回以降、
ユーザーに確認したい。
