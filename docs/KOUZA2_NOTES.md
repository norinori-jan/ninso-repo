# 人相講座2(全6回中2回目)動画からのノート

出典: 講座2の自動字幕(YouTube限定公開・日本語)を読み込んで整理したもの。
講座1と同じく、個別受講者(実名)への具体的な鑑定内容は除外し、一般化
できる技法のみを抜き出している。今回は**実演(生徒の顔を見ながらの実際
の鑑定)** だったため、ユーザーの指示により「今の実装と食い違う点は
これを正として直す」方針で、コードにも反映した。

## 今回、コードに反映した内容

### 1. 「天中」の意味づけを修正・拡張

- **修正前**: 「目上・官運・地位に関わるとされる部位」
- **修正後**: 「人相で最重要とされる部位。目上・官運・地位、および
  ご先祖からの加護に関わるとされる部位」

講座2では、天中(額の生え際中央)を「一番大事な部位」と明言した上で、
以下の具体的な読み方を教えていた:

- 天中から**明るい色で下る**線・色 → ご先祖からの加護・応援(精神的・
  金銭的な支え)が今もある、という意味
- 天中へ**暗い色でつながる**線・色 → 自分の力ではどうにもならない大きな
  出来事(裁判・不可抗力の事態など)に関わる相。「刑務所に入る人にも出て
  いる」という強い言い方もされていた

`app/app.js`の`buildMarkInterpretation()`に、天中を経路に含む線の場合の
専用分岐を追加した。検出済みの明暗ノート(`周囲より明るい`/`周囲より
暗い`)を使って、上記の2パターンを切り分けて解釈文を作る。

### 2. 線が通る部位をすべて拾うように変更

講座2では「裁判の線が兄弟のところを通ったら兄弟が関わってくる、田宅を
通ったら土地建物のことも財産も引っかかってくる」というように、**線が
経由する部位はすべてその相に関わってくる**、という考え方が繰り返し
説明されていた。これは講座1の「振動線」の説明とも整合する。

以前の実装は線の**始点と終点の2点だけ**で位置を判定していたが、これを
線が通る全ての点で位置判定し、連続する同じ部位をまとめた「経路」として
扱うように変更した(`gansouMark.suggestedRegionPath`)。解釈文は経路上の
全部位を「A→B→C」のようにつなげて表示する。

## 参考情報として記録(コードは未変更)

以下は具体的で参考になる内容だが、確度や実装コストの兼ね合いで今回は
コード変更を見送った。

- **裁判の線の向き**: 天中へ登る線は自分が裁判を起こす側、というように、
  向きによって当事者の立場が変わるという説明があった。ただし「向き」の
  判定は、静止画1枚からの線の描画方向だけでは決められない可能性が高く
  (実演では先生が手描きで描きながら方向を説明していた)、慎重を期して
  見送った。
- **警察という部位**: 教科書194ページの図にあるとのことだが、正確な座標
  が資料なしでは特定できないため追加を見送った。
- **夫婦宮の男女による左右差**: 男性は左、女性は右(またはその逆)が
  配偶者を表す、という趣旨の発言があったが、現在のアプリは利用者の
  性別を入力する仕組みがなく、`夫婦`は右側のみに定義されている。今回は
  実装を見送ったが、もし性別を考慮した判定を追加したいということであれば
  次回相談したい(前回の「位置を自分で選ばせない」方針とは矛盾しない
  入力だと考えている。性別は自己申告ではなく事実だから)。
- **出張線**: 夫婦宮から伸びる線があると配偶者が出張(単身赴任・遠方
  勤務)しがちで、浮気関係を疑うべきかどうかの判断材料になる、という
  実演があった。現状の「線の意味」機能を拡張すれば表現できそうだが、
  今回は見送り。
- **人中まわりの色の暗さ = アレルギー体質の可能性**という発言があったが、
  これは医学的な診断に近い内容のため、アプリには反映しないことにした
  (このアプリは伝統的解釈の紹介にとどめ、健康診断的な断定はしない方針)。
- **父母の不仲が夫婦運に影響する**という因果関係の説明があった。これは
  単一マークの解釈という今のアプリの設計(1マーク=1解釈、他のマークや
  全体評価とは無関係)とは相性が悪い(複数の部位をまたぐ因果関係の話に
  なるため)。今回は反映を見送ったが、記録として残す。
