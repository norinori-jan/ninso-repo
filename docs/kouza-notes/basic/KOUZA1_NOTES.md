# 人相講座1(全6回中1回目)動画からのノート

出典: 提供いただいた講座動画(約2時間)のYouTube自動字幕(日本語)を読み込んで
整理したもの。**自動音声認識のため、数字・固有名詞・専門用語に誤りが多く
含まれている可能性が高い。** 特に流年法の年齢の区切り、位置の左右、
部位番号は、実物の教科書・図と突き合わせての確認が必要。

**除外した内容:** 講座内でその場の受講者(実名)を対象に行われた個別鑑定
の具体的な内容は、個人情報にあたるためここには書き起こしていません。
一般化できる技法・考え方の部分だけを抜き出しています。また、仏壇・
ご先祖供養など人相と直接関係のない話題(ユーザーからも「顔相と関係ない
こともある」と事前に共有あり)も割愛しています。

---

## 1. 「画想(がそう)」「振動線」— このアプリの設計と直結する概念

講座の中で明確に説明されていた、本アプリの「隠れ相」機能の元になっている
考え方そのもの。

- **画想**: 顔の中に、絵のような像(人物・動物・建物など)が浮かび上がって
  見える現象。「女の人か家の絵が出てる」「牛とか馬も出るし色んな形が出る」
  というように、パレイドリア的に何かの形として顔の一部が見えることを指す。
  先生が実際に本(手描きの画想集)を使って教えている。
  → 家が焼ける絵が出れば火事、繁盛している店の絵が出れば商売繁盛、など
    「見えた像の内容がそのまま出来事の予兆」という読み方をしている。
- **振動線(しんどうせん)**: ニキビやホクロを通って皮膚に浮き出るように
  現れる、幅1mmほどの白っぽい線。「神が動く線」と表現されていた。
  最初から見える人もいれば、一生見えない人もいるとのこと(訓練で見える
  ようになる、という位置づけ)。
  → 本アプリの「線状のつながり(しわ・筋)」検出は、まさにこの振動線の
    考え方に近い。

## 2. 「着眼点」— 分析ではなく直感優先という方針

「駅想も人相もそうですが、パッと目につくところが着眼点です。そこから
展開していきます」「何かがパッと見て、あ、この人は◯◯相だな、と。そっから
入っていくんだ。分析したらダメですよ」との明言があった。

→ 本アプリの自動検出(サリエンス優先でまず目立つ箇所をマークし、そこから
  解釈を組み立てる設計)は、この「着眼点」の考え方と一致している。今回の
  一連の見直し(位置を自分で選ばせない、断定的に言い切る)の方向性も
  この講座の教え方と整合的だと言える。

## 3. 流年法(年齢と位置の対応)— 要確認・未実装

顔の各部位に年齢を割り当て、その部位のへこみ・盛り上がり・傷・色の
明暗で、その年齢での運気の浮き沈みを判断する技法。**具体的な数字は
音声認識の誤りが多く、教科書の図がないと確定できない。** 聞き取れた
範囲は以下の通り(要検証):

- 生え際(髪際)= 10歳が起点
- 眉頭の下あたりから両側に取っていく
- 鼻先(準頭)= 40歳
- 40歳より手前、頬骨・こめかみ付近に 37・47 などの数字も言及あり
  (位置関係が音声だけでは特定しきれず)
- 41〜60歳は口・顎まわり。**男女で左右が逆**(片方が先に来る)という
  説明があったが、どちらが先かは聞き取り不能
- 61歳以降は再び中心(顎の先など)に戻り、以後10年単位で繰り返す
  (「60、70、80、100までいく。何ぼでもいい」)
- その部位が凹んでいる/傷がある/色が暗いと、その年齢の頃に「わざわい・
  障害」が出やすいとされる。盛り上がって色つやが良ければ運気が上向く

→ **未実装。** もし今後実装するなら、年齢を入力してもらった上でその年齢に
  該当する位置を示す、という形になり、これは「自分で位置を選ぶ」問題とは
  別種の入力(年齢は自己申告ではなく事実)なので、今回の見直し方針とは
  矛盾しない。ただし数字の精度に自信が持てないため、教科書のページ写真を
  いただけると実装の精度が上がる。

## 4. 部位の左右・ジェンダーによる違い

- **父母宮(額の眉上あたり)**: 男性は左が父、右が母。女性は逆(右が父、
  左が母)、という趣旨の説明。ただし裏付けとなる具体的な発言箇所は
  1箇所のみで確度は中程度。
- **兄弟宮(眉のあたり)**: 「右の眉は男の兄弟」という発言があった
  (前後の文脈から、女の兄弟は左、という対比が想定されるが、明言部分は
  音声認識が崩れており未確認)。

→ 現在の`face-region-map.js`の「父母(右)」「兄弟(右)」のような左右
  バリエーションと、この左右の割り当てが一致しているか要確認。もし
  ずれていれば修正が必要。

## 5. 色つや(顔色)の基本ルール

一貫して「明るい色・つやがある = 良い」「暗い・濁った色 = 悪い」という
シンプルな二分法が使われていた。特定の部位に赤み(例: ニキビ)が出た
場合、その部位が象徴する人物(父母など)の健康・状態を暗示する、という
読み方が繰り返し出てきた。

→ 現在のアプリは明暗(「周囲より明るい/暗い」)は検出しているが、色相
  (赤み・青みなど)までは判定していない。今回は見送るが、将来的に
  肌色からの色相偏差を見る、という拡張の余地はある。

## 6. 骨相・五行・八相・八面(基礎理論、参考情報)

体型・姿勢・歩き方から見る「三質論」(がっしり型・ほっそり型・ぽっちゃり
型)、五行(木火土金水)の顔形、「八相」(尊相・威厳のある相・福相・
寿命の長い相・悪相・貧相・孤独の相など、古典からの抜粋)、「八面」
(江戸時代の分類: 男相・女相・子供っぽい相「目かけ面」など)といった
基礎理論の紹介があった。いずれも「教科書に書いてあるので読んでおくよう
に」という位置づけで、講座内での実演は少なめ。本アプリの`data/`配下の
解説文と重複・矛盾がないか、今後の回もあわせて確認したい。

## 7. 鼻を中心とした配置の考え方

「鼻は自分。鼻の左右が応援団(同僚・支え)」「目上・左右同僚・世間・
それから部下」というように、鼻を自分自身として中心に置き、周囲の部位に
人間関係(目上・同僚・部下・世間)を配置する考え方が説明されていた。
これは十二宮の基本構造(命宮・疾厄宮・兄弟宮など)とおおむね一致する。
法令線の左右は部下・同僚を見る、という発言もあった。
