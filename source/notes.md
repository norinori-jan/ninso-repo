## 第四輯: 骨相学概説(四) / 手相学概説(一)〜(三)

出典: 「第四輯」pp.124-173。前半は骨相学の続き(額の三分割・眉弓・頭形論・
民族比較)、後半は手相学の概説(掌の三質・指ごとの意味・親指の詳細・
掌面八卦・掌の色)。

### 採用

- 眉弓(眉丘)の発達と直観力・観察力 → `data/phrenology.js` に追記
- 額の三分割説(上部=推理、中部=記憶、下部=直観) → `data/phrenology.js` に追記
- 頭形(長頭・円頭)の一般概念 → `data/phrenology.js` に追記
  (※特定の民族・地域・人種と結びつけた記述は除外。下記参照)
- 手相全般(先天後天、三質論、指の関節・指先形状、親指の長短・節バランス・
  反り・指紋、人差し指〜小指の長短、掌の五行型、掌面八卦、掌の色、
  前腕の骨相) → 新規 `data/palmistry.js` として採用

### 除外(恒久方針・詳細不記載)

1. **民族・国民性と頭蓋骨相の比較**(p.130-137)
   長頭・円頭の指数を根拠に、英・仏・伊・西をはじめとする世界各地域の
   国民性を比較し、さらに特定人種について明確に蔑視的な性格記述を
   行っている箇所がある。差別的ステレオタイプを助長する内容のため、
   「そのような比較・記述が原本に存在した」という事実のみをここに記録し、
   具体的な内容・表現は転記しない。日本国内の地域差(東北=長頭・保守的、
   南九州=丸顔等)についても、同じ理由でセットで除外する。
   採用したのは「長頭・円頭という頭部の形態上の分類概念」そのものだけであり、
   特定の集団と結びつけない一般化した形で `head_shape_long_round` として
   採用している。

2. **手頸線(rascettes)の本数と不妊症・インポテンツの相関**(p.172)
   既存の「身体的特徴と生殖器官・体毛を結びつける俗信は詳細を記載しない」
   という方針の対象。事実の存在のみここに記録し、データ化はしない。

3. **掌の血色から特定の病名(胃腸病・肺病等)を示唆する記述**(p.164-171)
   運勢占いとしての血色判断(良い色/悪い色)自体は `palm_color_reading`
   として採用したが、「紫色なら肺病」等の具体的な病名への言及は、
   医療的な誤解を招く恐れがあるため採用しない。

4. **指の動き(喜怒哀楽等の「兆」占い)**(p.168-170)
   十本の指それぞれに喜・怒・哀・楽・思・望・欲・恐・衰・悪の十の兆しを
   割り当て、指がひとりでに動いたときの吉凶を占う内容。既存の
   options スキーマ(静的な形質からその人の性質を読む形)とは構造が異なる
   (「今この瞬間に起きた出来事」を占う形式)ため、今回はデータ化を見送る。
   将来的に別のデータ構造(例: `data/omens.js`)を用意する場合の候補として
   ここに記録しておく。

5. 巻末の参考書籍名(永鳥真雄・中村文聴・小西久遠・平竹辰の各氏の著作紹介)
   は、単なる出典紹介のため採用しない。

## 第五輯: 手相学概説(四)爪 / (五)丘・掌紋

出典: 「第五輯・第六輯」pp.174-215。爪の形・色・筋による診断、掌の7つの丘
(木星丘・土星丘・太陽丘・水星丘・火星丘・金星丘・月丘)、三大線(生命線・
感情線・知能線)と運命線・太陽線・健康線・結婚線などの掌紋各論。
巻末に読者質問コーナー(眉の傷跡と運勢、傷薬・毛髪用品の紹介)あり。

### 採用

- 爪の長さ・形(四角/丸/細長)・反り方・筋・白い斑点・半月・噛み癖・色
  → 新規 `data/palmistry_nails.js`(role="爪")
- 掌の7つの丘(木星・土星・太陽・水星・火星・金星・月)、指の付け根の
  指紋パターン(渦巻き/流れ紋) → 新規 `data/palmistry_mounts.js`
  (role="丘"/"指紋")
- 三大線(生命線・感情線・知能線)、副生命線、運命線、太陽線、健康線、
  結婚線、東西の呼び方対応、線上の年齢目安の考え方
  → 新規 `data/palmistry_lines.js`(role="掌紋")

### 採用にあたっての一般化

- 原本では爪の型に直接「脳溢血型」「マヒ症型」「心臓病型」
  「中風型・肺炎型」「カリエス型」という病名がつけられている
  (第四〜第九図)。医療的な誤診断・不安を招く恐れがあるため、
  これらの病名はデータに含めず、「体力・体質の傾向」という
  一般化した表現に置き換えて `nail_constitution_delicate` /
  `nail_shape_narrow` 等として採用した。
- 生命線の長短=寿命という単純な相関について、原本自体が
  「生命線が短い者は短命だとは的中しません」と否定的に言及している
  箇所があり、この俗説への注意書きも `line_life` にそのまま活かした
  (元の記述が健全な内容なので好んで残した)。

### 除外(恒久方針・詳細不記載)

1. **知能線の先端の「島」と、父親の性病(梅毒)の遺伝を結びつける記述**
   (p.211付近)。医療・性感染症・遺伝を結びつけた機微な内容のため、
   「そのような記述が原本に存在した」という事実のみ記録し、
   データ化はしない。
2. **女性の相を「不感症・不妊症の傾向」と結びつける記述**(p.213付近、
   インテリ階級の知能線の説明中)。既存の「身体的特徴と生殖器官・
   性機能を結びつける俗信は詳細を記載しない」方針の対象として
   不採用。
3. **小指の歪みを「発狂・自殺の相」と結びつける記述**(p.206付近)。
   精神疾患や自殺を身体的特徴と安易に結びつけるスティグマ的内容の
   ため不採用。事実の存在のみここに記録する。
4. **十二指腸虫等、爪に寄生する寄生虫の医学的な解説**(p.178-180)。
   性質診断のデータではなく、単なる医学豆知識のため対象外。
5. **巻末の読者質問コーナー**(富山県在住者からの、眉の傷跡と運勢に
   関する質問への回答、および傷薬・毛髪用オイル等の商品名を含む
   広告的な記述)。診断データではなく、個別相談・商品紹介のため
   採用しない。

## 恒久的な除外方針(累積サマリー)

新しいPDFを読み込む際、以下のカテゴリの内容は詳細を記載せず
「そのような発想・記述が原本に存在した」という事実のみを記録し、
データ化しない:

1. 性的な写真品評企画、身体的特徴と生殖器官・体毛・性機能を結びつける
   俗信(例: 不感症・不妊症・インポテンツとの相関)
2. 民族・人種を骨相・体格と結びつけて性格や優劣を比較する記述
   (差別的ステレオタイプを含むもの)。形態上の一般概念(長頭・円頭等)
   だけを、特定の集団に結びつけない形で抽出するのは可
3. 精神疾患・自殺を身体的特徴と安易に結びつけるスティグマ的な記述
   (例: 指の歪みと発狂・自殺の相関)
4. 特定の病名を診断的に示唆する記述(例: 爪の型が直接「脳溢血型」
   「心臓病型」等の病名になっているもの)。一般化した体質・体力表現に
   置き換えるのは可
5. 診断データそのものではない付随コンテンツ(読者質問コーナー、
   商品広告、寄生虫等の医学豆知識、参考書籍紹介)は単純に対象外
   (除外理由の記録も不要)

2. **巻末「観相秘録」の男娼・遊女面等の顔分類**
   若衆面・遊女面・妻面といった分類で、性風俗業(男娼業)の客層や
   商売の仕組みを解説する内容があった。人相学の一分野としてでは
   なく性風俗業の営業指南に近い内容であり、既存の除外方針の趣旨
   (性的な文脈で身体的特徴を消費目的に分類すること)に該当すると
   判断し、詳細は記載せず、そのような章が原本に存在したという事実
   のみここに記録する。

3. **毛髪にまつわる法医学トリビア・作家エピソード・読者投稿的余談**

   既存の除外方針5に該当するため対象外とした(記録も不要な区分)。

>    記録する。

- 鼻の相(人相学詳論(一)(八)):鼻の樹木比喩(幹・枝・花・実)、鼻の長さの基準、

   判断したため、診断データとしては採用せず、そのような記述が存在した事実のみ記録。

6. **具体的な塾生の実名イニシャル(I先生、S先生、C・N・T・Y・H各氏など)を用いた、
   兄弟姉妹の人数を眉から言い当てる実地修練の逐一の逸話**(第七輯232〜234ページ)
   → 個人が特定されうる余談的エピソードのため(除外方針⑤に準じる)、
   逸話そのものはデータ化せず、「眉から兄弟姉妹の人数を推測する」という
   原則のみを一般化した形で `eyebrow_sibling_count_reading` /
   `eyebrow_birth_order_zones` として採用した。

7. **鼻の凹凸型(鷲鼻・ユダヤ鼻型など)を特定の民族名で性格の悪さと結びつける記述**
   (第八輯257ページ付近)
   → 除外はしていないが、`nose_profile_curve_types` の該当オプション内に
   「特定の民族への偏見と結びつきやすい古い分類であり、現代的な性格判断としての
   根拠は薄い」旨の注記を加えることで、差別的読解を助長しないよう配慮した。

## 除外方針への追加提案

- 上記7のように、性格描写に民族名(ユダヤ鼻など)が直接使われているが、
  完全な除外ではなく注記つきで採用するケースが今回発生した。今後も同様の
  「特定の民族名を冠した相の俗称」が出てきた場合は、①完全除外、②民族名を
  外して形態のみ抽出、③注記つきで採用、のいずれかを都度判断する必要がある。
  次回引き継ぎプロンプトにこの判断基準を明記した。
