# 人相講座4(全6回中4回目)動画からのノート

出典: 講座4の自動字幕(YouTube限定公開・日本語、実演あり)。講座1〜3と
同様、個別受講者(実名)への具体的な鑑定内容は除外し、一般化できる技法
のみを抜き出している。定義の安易な変更はせず、技法にあたる内容のみを
実装候補として検討する方針も同じ。

## 「画想」検出の実演 — 現行機能の裏付け

講座4の実演で、父母宮のあたりに「点2つ(目)の下に口のような形」が
浮かび上がって見える、という具体的な指摘があった。これはまさに、直前の
セッションで実装した**「目・口のように並んだ構造(隠れた顔)」の
点3つ表示機能**が想定している現象そのもの。実演を通じて、この機能が
的外れな思いつきではなく、実際の講座で使われている読み方に基づいている
ことが確認できた。コード変更は不要(すでに実装済みのため)。

## 子供の人数・後継ぎに関する読み方(参考情報・未実装)

- 子供の人数は「パッと見て何人」と直感的に読む、という説明があった
  (講座1の「着眼点」の考え方の延長)。
- 「後取り(跡継ぎ)」は人中の状態(通っているかどうか)や、頬の横筋の
  有無から判断する、という説明があった。これは人中の既存の意味づけ
  (「子孫運・寿命に関わるとされる部位」)と矛盾しない内容だったため、
  定義の変更はしていない。

## 意図的に実装しなかった内容

- 父母の位置の色・線が悪い(白っぽい・色が濁っている)ことから
  「お父さんが亡くなっている」と判定する実演があった。講座3のノートで
  記録した通り、**生死に関する断定的な判定はこのアプリでは実装しない**
  方針を維持する。

## 次回への申し送り

- 5回目(5-1/5-2)・6回目はYouTube側の制限で字幕がまだ取得できていない。
  取得でき次第、同様に整理する。
- ここまで4回分を通じて、「線が通る部位はすべて意味に関わる」
  「天中の色による先祖/裁判の読み分け」「画想(目・口の点3つ)」という、
  すでに実装済みの技法が繰り返し裏付けられている。今後もし新しい技法が
  出てくれば実装候補にするが、部位の定義そのものは講座を聞いただけで
  安易に書き換えない、という方針を継続する。
