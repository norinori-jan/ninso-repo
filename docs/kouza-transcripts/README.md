# 講座字幕(基本編・上級編)

「人相講座」動画のYouTube自動字幕(srt形式・日本語)をそのまま保存した
もの。動画本体(数百MB〜)はリポジトリに含めず、テキストの字幕だけを
置いている。

## フォルダ構成(2026-08、基本編6回完走にあわせて整理)

```
kouza-transcripts/
  basic/       … 基本編(全6回、完走)の字幕
  advanced/    … 上級編(全6回、動画取得済み・字幕は順次追加)
```

整理ノート(`docs/kouza-notes/`)も同じ`basic/`・`advanced/`の構成に
揃えてある。1つの回に対して「字幕(このフォルダ)」と「整理ノート
(`docs/kouza-notes/`)」がペアになっている。

## 置いている理由

- 動画ファイルはgitリポジトリで扱うには大きすぎる(1本あたり200MB〜
  900MB超)。字幕テキストなら1本あたり150〜200KB程度で、リポジトリに
  含めても問題にならない。
- タイムスタンプ(`00:00:03,439 --> 00:00:06,359`のような形式)を残して
  あるので、後から「この解釈はどの発言に基づいているか」を動画の該当
  箇所に遡って確認できる(動画とのリンク)。
- 講座の内容を後から読み返して、`face-region-map.js`や
  `hidden-face-engine.js`の記述との整合性を確認したり、新しい回の内容と
  見比べたりする際の一次資料として使う。

## 注意

- YouTubeの自動音声認識によるものなので、専門用語・数字・固有名詞に
  誤りが多く含まれる。特に数値(部位の座標・年齢など)は、この字幕
  だけを根拠に実装しない方がよい。
- 講座内でその場の受講者(実名)に対して行われた個別の鑑定内容は、
  各`docs/kouza-notes/`側で意図的に除外している(個人情報のため)。
  この字幕ファイル自体には実名を含む発言がそのまま残っているので、
  再配布・公開の際は注意すること。
