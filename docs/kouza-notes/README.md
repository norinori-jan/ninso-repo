# 講座ノート(基本編・上級編)

各回の講座字幕(`docs/kouza-transcripts/`)を読み込んで整理した内容。

```
kouza-notes/
  basic/       … 基本編(全6回、完走)のノート
  advanced/    … 上級編(全6回、これから)のノート
```

## 一貫している方針(2026-08、講座2の訂正を受けて確立)

1. **部位の意味合い・定義(`face-region-map.js`の`meaning`など)は、
   講座を1回聞いただけで安易に書き換えない。** 複数回・複数資料で裏付けが
   取れたものだけを反映する。
2. **鑑定の技法(検出結果をどう読むか)は、明確でコードに落とし込める
   ものであれば都度実装してよい。**
3. **健康・生死・妊娠など、断定すると実害・精神的な影響が大きい内容は
   実装しない。** このアプリは娯楽としての人相解釈にとどめる。
4. **対話・問いかけを前提にした技法(占い師の意図が介在するもの)は、
   1枚の画像を自動解析する今のアプリの設計では表現できないため実装
   しない。**
5. 座標(部位の位置)が実物の図・教科書のページなしには特定できない
   ものは、確度が上がるまで実装を見送る。

各`KOUZAn_NOTES.md`は、この方針に沿って「実装した内容」「実装しなかった
内容とその理由」を分けて記録している。
